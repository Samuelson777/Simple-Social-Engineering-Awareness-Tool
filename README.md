# Simple Social Engineering Awareness Tool

## Overview
The Simple Social Engineering Awareness Tool is an interactive web-based quiz designed to educate users about common social engineering tactics such as phishing, pretexting, and baiting. The tool presents real-world scenarios and asks users to identify suspicious elements, providing immediate feedback and explanations to improve security awareness.

## Features
- Realistic social engineering scenarios with multiple-choice options  
- Immediate feedback and detailed explanations for each choice  
- Score tracking and summary display at quiz completion  
- Responsive design optimized for desktop and mobile browsers  
- Accessible interface with keyboard navigation support  

## Usage
1. Open the `index.html` file in any modern web browser (Chrome, Firefox, Edge, Safari).  
2. Read each scenario carefully and select the option(s) you believe are suspicious or safe.  
3. Review the feedback given for your selections.  
4. Continue through all scenarios and view your score summary at the end.  
5. Optionally restart the quiz to improve your awareness.

## Conclusion  
The Simple Social Engineering Awareness Tool is an interactive educational quiz designed to raise awareness about common social engineering tactics. By presenting real-world scenarios and providing immediate feedback, the tool helps users recognize potential social engineering attacks such as phishing, pretexting, and baiting. It promotes better security hygiene by educating users on how to identify and respond to suspicious communications, thus strengthening the human aspect of cybersecurity defenses.

## Restriction Warning  
This tool is intended for educational and awareness purposes only. It should not be used to engage in or promote any malicious activities. Users should always act ethically and legally when applying knowledge gained from this tool. Misuse for deceptive purposes may result in legal consequences.
